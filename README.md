# Attendly CSE 4 — Hyper

A fresh Next.js attendance companion with a calm macOS/iOS-inspired visual system.

## Included
- CSE 4 Group A routine
- Full subject names in visible UI
- 75% subject-level target
- Historical seeded attendance from 1 Aug 2026 (approximately 90%, clearly a seed)
- Present/Absent marking with correction support
- Safe skips and classes-needed calculations
- Calendar with supplied academic holidays
- Weekly timetable
- Dashboard insights and risk cards
- Quick search (Ctrl/Cmd + K)
- LocalStorage persistence
- JSON export/import backup
- Editable profile, target, subjects, holidays and group

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Note
The historical attendance is a user-requested starting seed, not verified college attendance data. Use Settings/marking to replace it with actual records.
